# Capa de red
## La idea en una oración
---
> La capa de red se encarga de direccionar paquetes a cada computadora en sí
## Desarrollo
---
Mientras que las direcciones MAC nos permite identificar los elementos físicos a los cuales mandarse, se es necesario un mecanismo para identificar de forma inequívoca

La capa de red contiene la funcionalidad que completa las capas inferiores para definir la interacción entre la red y el host. Acá se contiene las definiciones de *ruteo* y transferencia con destino, tal cual como un sistema de correo

# Interred o Internet
## La idea en una oración
---
> La interred es una forma de conectar distintas subrredes de distintos hardware y software entre sí, expandiendo la red desde redes más pequeñas
## Desarrollo
---
El Internet no es un "servidor gigante" en sí, sino una colección de redes más pequeñas interconectadas entre sí, incluso si cada subred tiene un hardware y software distinto de las demás que las haría incompatibles entre sí

Para determinar si es una interred o no, se determina dos reglas:
- Si varias organizaciones construyen distintas partes de la red y cada una se encarga de mantener su parte, es una interred
- Si la tecnología subyacente es distinta en diferentes partes, también es una interred

La *Puerta de enlace* es la máquina que se encarga de conectar dos o más redes y traducir entre las tecnologías dadas. Esta en una capa distinguida en la jerarquía de protocolos. No puede ser una capa muy baja o no se podrá conectar entre distintos tipos de redes, ni puede ser muy alta o sólo funcionará en ciertas aplicaciones. Tiene que ser la *capa de red* ideal

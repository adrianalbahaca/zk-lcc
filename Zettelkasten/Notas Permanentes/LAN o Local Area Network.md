# Local Area Network 
## La idea en una oración
---
> Las redes LAN conectan los dispositivos de un edificio o residencia. Cada computadora tiene un módem que se conecta a un punto de acceso para conectarse entre sí y entre el Internet y la red
## Desarrollo
---
Las conexiones LAN permiten conectar computadoras dentro de un mismo edificio o residencia entre sí para enviarse paquetes. Cada computadora contiene un *módem* tal que permite conectarse a las otras computadoras entre sí. Usualmente, se usa un *Punto de Acceso* *(AP)* para conectar esta red al Internet y viceversa

El estándar más usado para redes LAN inalámbricas es el *IEEE 802.11* o *WiFi*. Para las redes LAN alámbricas, se usa el estándar *IEEE 802.3* o *Ethernet* con una topología *punto a punto*, conectando cada computadora a un *Switch* para llevar sus paquetes adecuadamente

Usando la *VLAN*, es posible dividir una LAN física en varias LAN lógicas, ya sea etiquetando por "color" para que los paquetes sólo se envién dentro de un grupo de un determinado color entre sí usando los switches acorde

Se puede designar los tiempos de envío de forma *estática*, dando períodos fijos de tiempos para que las máquinas se comuniquen entre sí, y reenviando aleatoriamente si es necesario, o de forma *dinámica*, adaptando los tiempos a la demanda

# OSI: Open System Interconnection 
## La idea en una oración
---
> El modelo OSI se basa en principios bien definidos para la creación de capas
## Desarrollo
---
El modelo OSI sigue las siguientes reglas para cada capa
1. Se debe crear una capa cuando sea necesario un nivel distinto de abstracción
2. La capa debe estar bien definida
3. La función de la capa debe definirse tomando en cuenta las definiciones de los protocolos estandarizados internacionalmente
4. Se debe elegir los límites de la capa para minimizar el flujo de info a pasar en la interfaz
5. La cantidad de capas debe ser suficiente para que no se agrupen funciones distintas en capas iguales, pero no tan grande que se haga el sistema inmanejable

No es una arquitectura de red específica, sino que es más bien un modelo a seguir para los estándares a especificar
Mayormente, es el *modelo* lo que se usa, más no los *protocolos* estandarizados

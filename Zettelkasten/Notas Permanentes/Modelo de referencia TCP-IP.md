# TCP/IP: Modelo en la práctica
## La idea en una oración
---
> El modelo TCP/IP fue una arquitectura para resolver el problema de una red sin conexión confiable
## Desarrollo
---
El modelo TCP/IP nació como necesidad del *Department of Defense* de los EEUU de crear una red que permanezca funcional incluso si algunas de sus subestaciones se cortan súbitamente, ya sea por una explosión o una bomba

Este modelo se divide en 4 capas, las cuales son más prácticas que teóricas

# Multiplexación por división de tiempo
## La idea en una oración
---
> Cada usuario toma turno en recibir paquetes en todo el ancho de banda
## Desarrollo
---
Usando algún tipo de sistema para los turnos, cada usuario se le designa todo el ancho de banda durante una cierta ráfaga de tiempo. Para que funcione, se sincronizan en tiempo y se agregan *tiempos de guarda* para tener en cuenta las variaciones de sincronización

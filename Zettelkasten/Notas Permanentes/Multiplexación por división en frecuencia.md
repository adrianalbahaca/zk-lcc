# Multiplexación dividiendo en frecuencia
## La idea en una oración
---
> Se divide el espectro de banda completo en áreas donde cada usuario usa una cierta banda, dejando espacio entre sí
## Desarrollo
---
En un mismo medio, se divide todo el espectro de banda y se le asigna a cada usuario una cierta banda. Se deja un exceso entre cada banda para mantenerlas distanciadas entre sí, conocidas como *bandas de guarda*. Un ejemplo de esto es la radio AM. Su espectro es de hasta 1MHz y se trabaja con el rango de 500 - 1500 KHz

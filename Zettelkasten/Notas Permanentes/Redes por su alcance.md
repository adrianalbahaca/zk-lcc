# Clasificación de redes por su alcance 
## La idea en una oración
---
> Clasificar las redes por alcance implica usar la distancia en la que los dispositivos deben de estar para poder conectarse
## Desarrollo
---
Cada red tiene su propio rango de alcance para poder comunicarse entre sí. Para la distancia de una persona (1m), se tiene las *PAN* o *Personal Area Network*. Yendo a redes para propiedades privadas (10m - 1km), se tiene las *LAN* o *Local Area Network*. Aumentando a una ciudad se tiene las *MAN* o *Metropolitan Area Network* y finalizando para países o continentes están las *WAN* o *Wide Area Network*. La última escala, hasta ahora, es el *Internet* como lo conocemos

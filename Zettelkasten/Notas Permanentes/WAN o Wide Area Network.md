# Wide Area Network 
## La idea en una oración
---
> Las WAN son redes que conectan áreas alrededor de un área grande, como un país o entre continentes, usando líneas de transmición, enrutadores y distintos métodos para enviar paquetes a largas distancias
## Desarrollo
---
Las WAN conectan a través de un área del tamaño de un país o entre continentes

Para enviar paquetes entre *hosts*, la red que los conecta, o la *subred*, tiene las *líneas de transmisión* como alambres de cobre, fibra óptica o enlaces de radio para mover los bits entre máquinas, y los *enrutadores*, computadoras que se encargan de conectar dos o más líneas de transmisión para enviar cada paquete que recibe al destino adecuado. Básicamente, una LAN extendida con separación entre la comunicación y las aplicaciones, la forma clásica de hacer una red más grande

Las WAN permite conectar distintos tipos de tecnología a la red, haciendo estas redes cada una *interredes*. Así es como nos expandimos hasta lo que tenemos hoy como *Internet*, un montón de redes que forman redes más grandes, de las cuales se forman redes aún más grandes, conectadas entre sí

Se puede conectar a una WAN usando una *VPN*, rentando líneas de transmisión dedicadas para uno mismo, permitiendo tomar ventaja y tener las desventajas de la *virtualización*

Otra forma es que una empresa distinta opere la subred, siendo el *proveedor de servicios de red*, conectando a sus clientes entre sí y a su red con otras redes

De forma inalámbrica, tenemos la red de telefonía celular, permitiendo una WAN inalámbrica de altas velocidades, pero siendo más lenta que el Internet

(Al final, es un grafo gigante)
